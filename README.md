# Arishma Solutions — Website

Static business website for Arishma Solutions: fast, low-cost Apify scrapers
for Instagram, TikTok, Facebook, LinkedIn, YouTube, plus lead generation and
price tracking.

- Live site (planned): https://arishmasolutions.com
- Apify Store: https://apify.com/arisma_tech
- Contact: contact@arishmasolutions.com
- API (planned): https://api.arishmasolutions.com

## Deploy

This is a single self-contained `index.html` — no build step needed.

- **Cloudflare Pages:** connect this repository, no build command, output
  directory = repository root.
- **Any static host:** serve `index.html` from the repository root.

## Editing

Edit `index.html` directly. It contains the full page (markup, styles, and
scripts) in one file.
