Questions

Before you run your first Actor

Do I need an Apify account? +

Yes — our Actors run on Apify. A free Apify account is enough to test; you pay per result plus Apify’s platform usage shown transparently in the Console.

Do I need to provide my social media login? +

For most Actors, no — for example, the LinkedIn Job Scraper uses public data with no login or cookies. If an Actor ever needs a session for a specific target, its store page says so clearly before you run it.

What format do I get the data in? +

Every run produces a dataset you can download as JSON, CSV or Excel, or access via API. Field lists are documented on each Actor’s page.

Can you build a scraper for a site you don’t list? +

Yes — custom Actor development is a core service. Tell us the source, the fields you need, and how often it should run, and we’ll scope it for you.

Can I schedule recurring extraction? +

Yes. Apify schedules let any Actor run hourly, daily or weekly, with results delivered to storage, webhooks or integrations.

Tell us what data you need

Custom scraper, a field added to an existing Actor, or a REST API to serve the data — send a short brief and we’ll reply with next steps and a clear price.
